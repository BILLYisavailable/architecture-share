# Architecture Share

Presentation by Yuxuan Wang on efficient large language model architecture.

**[Open the presentation](https://billyisavailable.github.io/architecture-share/)**

Topics:
- Model structure, computation, and inference workloads
- Attention architectures: GQA, MLA, sparse, linear, and hybrid attention
- Other architectural modules

Use the arrow keys to navigate. A link ending in `#37`, for example, opens slide 37.

The website is a self-contained Marp HTML presentation. Figures and mathematics are bundled in `index.html`.
GitHub Pages publishes the root of the `main` branch. To update the presentation, replace `index.html` with the newly exported version.
